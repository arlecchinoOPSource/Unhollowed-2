# Privacy verification

Verification for U2-P6-04. It checks what the app stores, sends, and logs against what the product claims. The user-facing privacy statement is part of U2-P6-20 and should copy only what is verified here. Commit `e76fc3a`, macOS arm64.

## Claims and evidence

| Claim                                   | Result                        | How it was checked                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Works without internet                  | Verified in the browser build | `tests/browser/privacy.spec.ts` blocks every request that is not the local dev server, visits 11 routes, and requires zero blocked requests and no page errors. A canary request proves the blocker works. The packaged app was not run with the network disabled (see Gaps).                                                                                                                                                                                    |
| No outbound requests from app code      | Verified                      | `tests/unit/privacy.test.tsx` fails if any frontend file uses `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon`, or a service worker. `Cargo.toml` has no HTTP client (`reqwest`, `ureq`, `hyper`). The CSP also limits `connect-src` to the local IPC channel.                                                                                                                                                                                |
| No remote assets                        | Verified                      | Same test fails on remote `src`, `href`, `url()`, or `@import`. The font (Inter) is bundled from `@fontsource-variable/inter`.                                                                                                                                                                                                                                                                                                                                   |
| No accounts                             | Verified                      | No sign-in, token, or credential field exists in the UI, the schema, or the commands.                                                                                                                                                                                                                                                                                                                                                                            |
| No telemetry or analytics               | Verified                      | No analytics or error-reporting dependency in either manifest (test above). No code path sends data anywhere.                                                                                                                                                                                                                                                                                                                                                    |
| No automatic uploads of documents       | Verified                      | The only network code is the user-initiated update check, which sends no workspace data ([Updater](UPDATER.md)). Documents leave the app only through a native Save dialog the user completes.                                                                                                                                                                                                                                                                   |
| No sensitive data in logs               | Verified by source review     | No `console.*` call in the frontend (test above). Rust has 25 `eprintln!` calls to standard error, one per failure site: each prints a fixed sentence plus the database or I/O error, never a record's text. A few also print a record id or the file path the user chose. Release builds on Windows use the GUI subsystem, so nothing is shown; on macOS they appear only when launched from a terminal or collected by the system. The app writes no log file. |
| Local files and backups handled clearly | Verified                      | Files are only read or written after a native dialog. Habit pre-restore copies go to `habit-copies` inside the app data folder, created with owner-only permissions on macOS (`0700`).                                                                                                                                                                                                                                                                           |

## What is stored locally, and whether it is encrypted

Nothing is encrypted by the app. Everything below is ordinary unencrypted data protected only by the operating system's account permissions. The app does not defend against someone who can read the user's files or has access to the device.

| Data                                                                                            | Where                                                                                                                                                                           | Encrypted |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| All workspace records (projects, issues, documents, images, calendar, habits, mood, dashboards) | One SQLite file, `workspace.sqlite3`, in the app data folder (`~/Library/Application Support/dev.arlecchino.unhollowed2/` on macOS; the matching `%APPDATA%` folder on Windows) | No        |
| Unsaved document drafts                                                                         | Webview `localStorage`, key `unhollowed-2-document-draft:<id>`, until the document is saved                                                                                     | No        |
| Interface preferences (theme, calendar view, dashboard controls)                                | Webview `localStorage`, keys `unhollowed-2-appearance`, `unhollowed-2-calendar`, `unhollowed-2-dashboard`                                                                       | No        |
| Habit pre-restore copies                                                                        | `habit-copies/` in the app data folder, JSON, owner-only on macOS                                                                                                               | No        |
| Files the user exports (JSON, CSV, ICS, document formats)                                       | Wherever the user chooses                                                                                                                                                       | No        |

Deleting the app data folder and the webview storage removes everything. Uninstalling the app may leave them behind (to be confirmed by U2-P6-17 and U2-P6-18).

## Gaps

- The packaged app was not started with the network disabled, and no packet capture or firewall log was taken. The evidence is the browser build plus source and dependency checks. Repeat on the packaged macOS and Windows builds (U2-P6-17, U2-P6-18) with the machine offline.
- Windows storage paths and permissions are documented from Tauri's behavior, not observed.
- The operating system's own webview may contact its vendor (for example for spell-check or crash reporting). That is outside the app's code and was not examined.
