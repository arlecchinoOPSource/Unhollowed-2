# Unhollowed 2 v1.0.0-beta.1 (draft release notes)

**Status: draft.** The version has not been bumped (the app is still `0.1.0`), no tag exists, and nothing is published. Publishing needs the owner's approval and the open decisions at the end of this page. This is a **prerelease**.

## What this is

The first public beta of Unhollowed 2, a free, local-first desktop workspace for documents, projects and issues, a calendar, habits, mood check-ins, and dashboards. It works offline, needs no account, and keeps all data on your computer. Read the [user guide](../USER_GUIDE.md) and the [privacy statement](../PRIVACY_STATEMENT.md).

## Highlights

- Home and Today views with overdue, due, scheduled, and recent items.
- Projects with goals, and issues with priorities, dates, labels, milestones, relationships, repeats, a list and a board, saved views, and search.
- A rich-text document editor with tables, images, fonts, page layout, folders, templates, links, a link graph, version history, and import and export for Word, Markdown, text, and HTML.
- A calendar with day, week, work week, month, and agenda views, repeating events, time zones, reminders, and ICS import and export.
- Habits with a grid, history, and backup, mood check-ins, and arrangeable dashboards.
- Light and dark themes, keyboard-accessible controls, and local-only storage.

## Known limitations

- **Beta quality.** It can have bugs that lose or damage data. Keep your own backups.
- **No full in-app backup**; copy the data folder by hand ([Backup](../BACKUP.md)). After a crash, copy the `-wal` file too.
- **Nothing is encrypted**; use FileVault or BitLocker.
- **Unsigned installers**; expect warnings. The first install on a PC without WebView2 and without internet fails until WebView2 is installed.
- **Word import** drops paragraph alignment, fonts, sizes, and page breaks; block quotes become paragraphs.
- Installing a newer installer over an older one, Windows 10 and 11 client machines, the macOS DMG from CI, and any screen-reader use were **not tested**. Independent user testing has **not** been run.
- Supported only on macOS Apple Silicon and Windows x64. The minimum macOS version is untested.
- One advisory is deferred: the bundled SQLite version (a crafted database plus a mismatched log file placed in the data folder can expose stale memory). It needs a local attacker who can already write your files; the fix needs a library release that is still pre-release ([Dependencies](../DEPENDENCIES.md)).
- A document title that is only a NUL character shows a generic save error.
- No open-source license has been chosen yet ([Legal](../LEGAL.md)).

## Before publishing (owner decisions)

1. Approve `1.0.0-beta.1` and the MSI version mapping `0.99.N` ([Versioning](../VERSIONING.md)), then merge a release PR that sets the version everywhere and adds the MSI version.
2. Choose a license, the copyright holder, and the publisher name ([Legal](../LEGAL.md)); add the 21 missing license texts to the notices.
3. Decide on Developer ID signing and notarization for macOS and a code-signing certificate for Windows, or publish as an unsigned internal beta.
4. Decide whether to ship with the known limitations above, in particular the manual backup and the Word import loss.
5. Run the manual native checklists and the usability sessions ([Acceptance](../ACCEPTANCE.md), [Usability testing](../USABILITY_TESTING.md)) if they are required for this release.
6. Create the tag from the reviewed commit; the packaging workflow verifies it ([Release](../RELEASE.md)); then create a draft release, mark it a prerelease, and publish only with explicit approval.
