# Unhollowed 2 v1.0.0-beta.1 (draft release notes)

**Status: draft prerelease notes.** Candidate validation and explicit owner approval are required before publication.

## What this is

The first public beta of Unhollowed 2, a free, local-first desktop workspace for documents, projects and issues, a calendar, habits, mood check-ins, and dashboards. It works offline, needs no account, and keeps all data on your computer. Read the [user guide](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/docs/USER_GUIDE.md) and the [privacy statement](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/docs/PRIVACY_STATEMENT.md).

## Highlights

- Home and Today views with overdue, due, scheduled, and recent items.
- Projects with goals, and issues with priorities, dates, labels, milestones, relationships, repeats, a list and a board, saved views, and search.
- A rich-text document editor with tables, images, fonts, page layout, folders, templates, links, a link graph, version history, and import and export for Word, Markdown, text, and HTML.
- A calendar with day, week, work week, month, and agenda views, repeating events, time zones, reminders, and ICS import and export.
- Habits with a grid, history, and backup, mood check-ins, and arrangeable dashboards.
- Light and dark themes, keyboard-accessible controls, and local-only storage.

## Known limitations

- **Beta quality.** It can have bugs that lose or damage data. Keep your own backups.
- **No full in-app backup**; copy the data folder by hand ([Backup](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/docs/BACKUP.md)). After a crash, copy the `-wal` file too.
- **Nothing is encrypted**; use FileVault or BitLocker.
- **Unsigned installers**; expect warnings. The first install on a PC without WebView2 and without internet fails until WebView2 is installed.
- **Word import** drops paragraph alignment, fonts, sizes, and page breaks; block quotes become paragraphs.
- Installing a newer installer over an older one, Windows 10 and 11 client machines, the macOS DMG from CI, and any screen-reader use were **not tested**. Independent user testing has **not** been run.
- Supported only on macOS Apple Silicon and Windows x64. The minimum macOS version is untested.
- **Bundled SQLite advisory (CVE-2026-119375).** This beta contains an affected SQLite version. RustSec rates the local information-disclosure issue medium. It applies when the app opens workspace files that a less-trusted party can write. Restore only trusted backups. The upgrade to a patched SQLite dependency is deferred for this beta. [RustSec advisory](https://rustsec.org/advisories/RUSTSEC-2026-0459.html) · [Dependency notes](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/docs/DEPENDENCIES.md)
- A document title that is only a NUL character shows a generic save error.
- Unhollowed 2 is distributed under the [MIT License](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/LICENSE). The installers include the [third-party notices](https://github.com/arlecchinoOPSource/Unhollowed-2/blob/main/THIRD_PARTY_NOTICES.md).
