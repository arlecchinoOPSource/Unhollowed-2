# Unhollowed 2 v1.1.0-beta.1

This beta introduces on-demand desktop updates. Open **Check for updates** at the bottom of the sidebar when you want to check. Unhollowed opens normally and makes no updater requests at startup.

## Install this beta manually once

Version `1.0.0-beta.1` cannot update itself. Download the new installer for your existing platform and installer family. Keep NSIS and MSI installations separate. Back up your workspace and quit Unhollowed before replacing the app. Subsequent compatible releases can be installed from inside the app once they are approved for the beta channel.

The updater verifies package signatures and saves pending document changes before installation. macOS and Windows may show platform trust warnings if the installer lacks OS signing or notarization. Updater package signatures are separate from OS signing.
