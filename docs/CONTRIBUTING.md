# Contributing

Use GitHub Issues to propose or select work. Agree on scope and acceptance criteria, then branch from `main`. Follow the branch naming and compatibility guidance in [AGENTS.md](../AGENTS.md).

Open a focused PR to `main` and link the issue. Include local checks, platform details, and any verification gaps. Use sample data in screenshots and redact machine-specific or private information from logs. Review CI and finish the relevant native checks before merging.
